# NeuroScan-AI

# 🧠 Brain Tumor Detection Using Deep Learning

## 📌 Overview
Brain Tumor Detection using Deep Learning and MRI Images. This project uses Convolutional Neural Networks (CNN) to classify MRI brain scans as tumor or non-tumor with high accuracy using TensorFlow, Keras, and OpenCV.
This project detects brain tumors from MRI scan images using Deep Learning techniques.  
A Convolutional Neural Network (CNN) model is trained to classify MRI images into:

- Tumor
- No Tumor

The project helps automate medical image analysis and supports early diagnosis.
